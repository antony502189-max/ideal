# ideal — web prototype

Интерактивная веб-версия основных экранов Android-приложения, собранная по структуре и визуальным токенам из `res`.

## Реализовано

- главная страница и форма поиска;
- выдача объектов, фильтры, сортировка и карта;
- подробная карточка объекта;
- избранное с сохранением в `localStorage`;
- поисковые оповещения;
- список чатов и работающая переписка;
- профиль, меню и тёмная тема;
- адаптивная мобильная и десктопная компоновка.

## Запуск

Проект не требует сборщика или зависимостей. Откройте `index.html` через любой статический HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Структура

- `index.html` — точка входа;
- `styles.css` — дизайн-система и адаптивная вёрстка;
- `app.js` — маршрутизация, состояния и интерактивные сценарии;
- `assets/` — иллюстрации интерфейса.

Это самостоятельный фронтенд-прототип с демонстрационными данными. Серверные API, авторизация и реальные объявления исходного приложения в репозиторий не входят.
